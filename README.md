# 🎰 Slot Machine Game (Node.js)

This is a simple command-line slot machine game built using JavaScript.

## 🚀 Features

* Deposit money
* Choose number of lines (1–3)
* Place bets
* Spin the slot machine
* Win based on matching symbols

## 🛠️ Technologies Used

* Node.js
* JavaScript

## ▶️ How to Run

1. Install Node.js
2. Install dependency:

   ```
   npm install prompt-sync
   ```
3. Run the game:

   ```
   node index.js
   ```

## 🎮 Game Rules

* You can bet on 1 to 3 lines
* Matching symbols in a row = win
* Different symbols have different values

## 📂 Project Structure

* index.js → Main game logic
